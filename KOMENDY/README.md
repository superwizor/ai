## 💻 BACKEND & TESTY

### 🚀 Uruchomienie Środowiska
> Odpala bazę (proxy), migracje i 5 mikroserwisów w tle. Zostaw ten terminal otwarty.
```bash
./KOMENDY/1
```

### 🧪 Testy Integracyjne E2E
> Odpala testy integracyjne w nowej zakładce terminala (`Cmd + T`).
```bash
./KOMENDY/2
```

## 📱 APLIKACJA FLUTTER
